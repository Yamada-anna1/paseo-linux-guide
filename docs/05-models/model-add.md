# 手动添加模型

[返回首页](../../README.md) · [本分类目录](README.md)

服务商支持模型，但菜单没有时，补充准确 Model ID。

执行位置：**Paseo 界面** · 分类：模型与服务商

## 添加之前

先从实际服务商的模型清单确认准确的 Model ID。界面显示名称是标签，不能据此推断接口一定支持同名模型。

## 界面操作

- 在模型菜单点击 Codex 右侧的齿轮，进入当前主机的提供方设置。
- 找到“添加 Model / Add model”。不同版本入口位置可能变化。
- Model ID 填写服务商接受的准确标识。
- 如果另有名称字段，填写自己容易辨认的显示名称。
- 保存后重新打开模型菜单，在新测试会话中选择它。

下面只给占位符。请替换为当前账号或接口实际支持的准确 Model ID，不要把 YOUR_MODEL_ID 原样保存为模型名称。

**Model ID 示例 · 需先确认服务商支持**

```text
YOUR_MODEL_ID
```

**显示名称示例**

```text
My Model
```

## 用最小请求验证

**发送给新会话的测试内容**

```text
只回复 OK，不读取或修改文件。
```

| 结果 | 含义 |
| --- | --- |
| 成功回复 | 当前配置下模型请求可完成 |
| model_not_found | 核对准确 ID、接口地址和该接口支持的模型 |
| 权限或认证错误 | 核对账号权限、API Key 或服务商配置 |
| 菜单没有添加入口 | 先检查 Paseo 版本和当前提供方设置，不能直接套用其他版本的界面 |

> **添加菜单项不会开通模型**
>
> 手动添加只让 Paseo 可以选择该 Model ID，不会为账号增加权限，也不会让第三方接口自动支持它。
