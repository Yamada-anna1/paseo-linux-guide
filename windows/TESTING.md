## 测试中实际发现并修复的问题

1. PATH 中存在多套 OpenSSH 时，程序发现可能返回多个路径。现显式选择一个可执行文件，并增加多安装场景检查。
2. 下载文本以 scriptblock 执行时，本地入口必须保存当前脚本本身，而不是调用它的外层脚本。已增加完整源文本一致性断言。
3. 英文 Windows 下中文快捷方式名可能保存失败。现使用英文图标名、中文说明，并提供快捷方式失败时的本地入口。
4. 带空格路径与 Windows 原生命令参数转义经过独立测试和真实 OpenSSH `-G` 解析验证。
5. 独立仓库发布后的真实 HTTPS 入口测试发现 PowerShell 5.1 可能保留文本中的 UTF-8 BOM。入口现显式移除开头 U+FEFF 后再解析；已增加带 BOM 的单元测试与两个 PowerShell 版本的公开下载入口测试。原始本地 `.ps1` 仍保留 BOM 以正确显示中文。

## 不能据此保证的事情

- 没有连接或改动用户的真实服务器、真实 SSH 私钥、真实授权文件或桌面。所有测试密钥、配置、快捷方式都在测试目录中创建。
- Windows 测试包含真实本地 OpenSSH 程序与隔离的流程模拟；跨端真实 SSH 场景在 Ubuntu 的 PowerShell 7 中完成。没有把它描述为每一种 Windows/SSH 服务器组合都经过实机测试。
- 真实 SSH 自动化测试用临时已授权密钥完成初始登录，不存储或自动输入密码。人类输入密码、私钥口令和 UAC 的交互路径仍受本机策略影响。
- 不覆盖所有发行版、企业策略、代理/跳板机、自定义 sshd 启动参数或非 ED25519 密钥。最终没有显示 `SSH_OK` 就不能视为成功。
- 独立仓库发布后会再次运行同套 CI。后续版本以各自 Actions 结果为准，不把本报告当作未来版本的永久保证。
